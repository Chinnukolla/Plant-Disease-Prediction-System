# Plant-Disease-Prediction-System
An AI-powered web application that detects and predicts plant leaf diseases using Machine Learning. Users can upload a leaf image to identify the disease and receive the predicted result with confidence.

# 🌿 Plant Disease Prediction System

## About the Project

The Plant Disease Prediction System is a machine learning-based web application developed to identify diseases in plant leaves from uploaded images. The main goal of this project is to provide a simple and efficient way to detect plant diseases at an early stage, helping farmers and agriculture enthusiasts take timely action.

The application allows users to upload an image of a plant leaf, processes the image using a trained machine learning model, and predicts the most likely disease along with its confidence score.

---

## Features

- Upload plant leaf images for disease detection
- Predict plant diseases using a trained machine learning model
- Display the predicted disease name and confidence score
- Simple, clean, and easy-to-use web interface
- Fast prediction results

## How to Run the Project

### Step 1: Clone the repository

```bash
git clone https://github.com/your-username/Plant-Disease-Prediction-System.git
```

### Step 2: Open the project folder

```bash
cd Plant-Disease-Prediction-System
```

### Step 3: Install the required libraries

```bash
pip install -r requirements.txt
```

### Step 4: Start the application

```bash
python app.py
```

After running the application, open the local URL displayed in the terminal (usually `http://127.0.0.1:5000`) in your web browser.
